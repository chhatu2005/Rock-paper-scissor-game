# 🎮 Rock Paper Scissors Game | Day 24 – Veda Technology Internship

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, check the result, and track the score.

## ✨ Features

- Three choices: Rock, Paper, and Scissors
- Computer makes a random choice
- Displays Win, Lose, or Draw result
- Tracks the player's score
- Tracks the computer's score
- Reset Score button to restart the game
- Interactive buttons with hover effects
- Responsive design for mobile and desktop devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select Rock, Paper, or Scissors.
5. View the result and updated score.
6. Click Reset Score to start again.

## 🎯 Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both choices are the same, the result is a Draw.

## 🧠 How It Works

1. The player selects one of the three choices.
2. JavaScript randomly selects a choice for the computer using `Math.random()`.
3. Conditional statements compare both choices.
4. The game displays the result and updates the scores.
5. The Reset Score button resets both scores to zero.

## 📚 Learning Outcomes

This project helped me practice JavaScript conditional statements, random number generation, functions, DOM manipulation, event handling, and score management.
